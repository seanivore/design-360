# shop-admin demo — live CDN URLs

All media for the `shop-admin` demo is uploaded to `cdn.august.style` and **verified live (HTTP 200)** — 92 images (`.webp`) + 3 videos (`.mp4`) = 95 objects. This is the hand-off list for Claude Design: every URL below is what `data.js` should reference. Images were optimized to WebP through the upload API; videos went straight to the CDN.

Base: `https://cdn.august.style/media/shop-admin/<slug>/`. Order per product: hero · gallery 1…N · checkout · thumbnail · poster · video.

> **No upload (already live elsewhere):** `the-clockmakers-window` and `first-snow-stillwood` load from the Everlastings dev CDN (`https://cdn.everlastingsbyemaline.com/test/<slug>/…`). A 404 there is a harmless broken-image fallback.
