#### Storytelling Media Flow Placement

**Replacing the two column layout**

The following components are used to replace the two column layout in specific entries:

  + Can be static .webp images, .gif animations, or a mix of both
  + The number next to "flow-1" "flow-2" represents the placement going down the page 
  + Starting with a text block, visual media and text will alternate through the flow until the end of either the last image or text block 
  + This allows for a more dynamic storytelling experience that the slideshows and other projects were lacking 
  + The alt tag will be the same for all visual media in the series

```json
  "flow_txt": [
    "This is a line of flow text, the first.",
    "This is a second line of flow storytelling text."
  ]
  "flow_img": [
    "https://cdn.august.style/media/{slug}/flow-1-{slug}.webp",
    "https://cdn.august.style/media/{slug}/flow-2-{slug}.gif"
  ],
  "flow_alt": "",
```
