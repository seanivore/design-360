# Web Assets Showcase Portfolio 

[https://design.august.style](https://design.august.style)

## About 

This website showcases web development, design, and user experience capabilities through a collection of high-demand digital assets by pulling from actual past projects making them highly polished, then creating a walled garden UX/UI. This is effective without waisting the viewer's time. 

### Goals
  - Show common website UX flows & modern design patterns
  - Expand current portfolio, while targeting B2B/B2C 
  - Micro-interactions and loading states
  - Responsive layouts & accessibility considerations

### Value
  - Shows understanding of multi-step user journeys
  - High quality in different styles demonstrate versatility 
  - Practical value shows just what they need
  - Code structure allows for quick brand color swaps
