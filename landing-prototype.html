Frequently Asked

"You do... everything?"
Not everything — but I've shipped production work as a web developer, graphic designer, video editor, and automation engineer. The common thread is systems thinking: I see how pieces connect and build the connective tissue between them. Most "generalists" are actually specialists who got bored.
"Can a generalist go deep enough?"
Look at the SaaS conversion flow — that's production JavaScript with custom CSS animation, responsive design, and conversion optimization. Look at the 800-product store — that's Make.com, Notion, Webflow CMS, and Python all integrated. These aren't surface-level.
"What's your tech stack?"
For web: vanilla HTML/CSS/JS, no frameworks. For automation: Python + Make.com + Notion. For design: Figma, Photoshop, Illustrator, After Effects. For AI: Claude/Cursor for development, Midjourney for generative design. I pick the tool that fits, not the one I'm most comfortable with.
"Why no React / Next.js / Tailwind?"
Because I don't need them for what I build. This portfolio runs on GitHub Pages with zero build steps — pure HTML, CSS, JS, and JSON. No bundler, no node_modules, no deploy pipeline. Sometimes the best engineering decision is choosing not to over-engineer.
"How do you use AI in your work?"
AI is a power tool, not a replacement. I pair-program with Claude/Cursor for development, use Midjourney for generative design exploration, and build automation workflows that leverage AI for content processing. The key is knowing when AI accelerates and when it gets in the way.
